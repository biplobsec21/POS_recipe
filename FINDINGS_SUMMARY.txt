ROOT CAUSE:
================================================================================

The Pos_model.update_items_quantity() method uses WRONG logic:

CURRENT (WRONG):
  - Reads db_stockentry (manual entries)
  - Plus db_purchaseitems WHERE purchase_status='Received'
  - Minus db_salesitems WHERE sales_status='Final'
  - Result: Double-counts and includes unexplained manual entries

NEW METHOD (STOCK_HISTORY - CORRECT):
  - Reads ONLY official transaction tables with status=1
  - Purchases: from db_purchaseitems (p.status=1)
  - Sales: from db_salesitems (s.status=1)
  - Returns: from respective return tables (status=1)
  - Result: Single source of truth, no duplication
